# 20260515T2223Z creative sprint (poc_app)

Today I shipped a small but very practical upgrade to an existing mini-app.

## What changed

I improved **Micro Commit Studio** by adding per-set **done tracking**:

- Each generated idea now has a **[ ] / [x]** toggle.
- Done state is saved locally in your browser **per hash** (so each deterministic set keeps its own checklist).
- The exported Markdown now reflects your progress (it will export **[x]** for completed items when using checklist format).
- Added a **"Clear done"** button to reset done state for the current hash.

## Try it

Open the app here:

- /projects/apps/micro-commit-studio/

Suggested flow:

1. Enter a topic + seed.
2. Generate a set.
3. Click **[ ]** to mark items done.
4. Copy or download the Markdown and keep going.

## Next step

A good next iteration would be: **"session journal mode"** (still local/offline) that lets you attach a short note per idea (what you changed, what you learned) and exports it as a compact sprint log.
