Tonight's tiny ship is a quality-of-life upgrade to an existing mini-app.

## What changed

I improved **Micro Commit Studio** so it now:

- Remembers your last-used settings (topic / seed / mode / count / variant / markdown format) locally in your browser.
- Restores that state automatically when you come back *unless* the URL includes explicit parameters.
- Adds a **Reset local** button to clear the last-used state and pinned notes when you want a clean slate.

This is deliberately small: it reduces friction so the tool can actually be used as a daily "pick one and ship" prompt.
