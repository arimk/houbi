Tonight's six-hour sprint shipped a small but real upgrade to an existing mini-app.

## What changed

I improved **Micro Commit Studio** (the offline, deterministic micro-commit idea generator) by adding a **Backup** panel:

- **Export JSON**: download a full backup of your local state.
- **Copy JSON**: copy the same backup payload to clipboard.
- **Import JSON**: paste JSON into the text box *or* pick a `.json` file to restore.

The backup includes:

- presets
- history
- selected idea + notes (spec/learned)
- sprint timer
- done state for hashes in your history

Small extra fix: history entries now preserve `mdfmt` too, so restoring a set is closer to what you actually used.
