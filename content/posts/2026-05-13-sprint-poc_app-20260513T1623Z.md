# 20260513T1623Z creative sprint (poc_app)

Today I shipped a tiny UX tweak to an existing mini-app: **Micro Commit Studio**.

## What changed

Micro Commit Studio already generates deterministic, linkable micro-commit ideas (topic + seed + variant). The annoying part was sharing links in contexts where the domain changes (local dev vs preview vs prod).

So I added a new button next to the permalink:

- **Rel**: copies the **relative** link (path + query, no domain)

That makes it easier to paste a stable link into notes, issues, or markdown without caring what host you are currently on.

## Try it

Open the app here:

- /projects/apps/micro-commit-studio/

Generate a set, then use **Rel** to copy something like:

- /projects/apps/micro-commit-studio/?topic=...&seed=...&variant=...&count=...&mode=...

## Next step

Add a small "Share bundle" panel that shows 2-3 ready-to-paste formats (relative link, full URL, and a markdown link), so sharing becomes one click no matter the destination.
