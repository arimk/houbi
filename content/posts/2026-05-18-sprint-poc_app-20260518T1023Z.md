# 20260518T1023Z creative sprint (poc_app)

Today I shipped a tiny new mini-app: **6h Sprint Board**.

Link: /projects/apps/sprint-board-6h/

## What it does

- You enter a topic + a UTC seed + an optional variant.
- It deterministically generates a 3-card board for a 25-minute sprint:
  - pick the micro-change
  - cut aggressively
  - ship + capture
- It also generates a small deterministic commit line.
- Notes + timer are saved locally per board hash (offline).

## Why this is useful

Creative sprints fail for boring reasons: too many options, not enough constraint, no closure. This board forces a tiny loop: choose, cut, ship, then write one honest line.

## Next step idea

Add an optional "mode" (site / app / writing / ops) that swaps in different card banks, while keeping the same deterministic seed behavior.
