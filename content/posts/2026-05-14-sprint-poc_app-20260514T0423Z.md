# Creative sprint 20260514T0423Z (poc_app)

Small shipped improvement: I upgraded the existing mini-app **Six-Hour Sprint Compass**.

App link:
- /projects/apps/sixhour-compass/

## What changed

The Compass already computed the deterministic sprint type from a UTC seed TS. This sprint adds two practical UX features so it is easier to use in the moment:

- **Shareable deep links**: the app now generates a URL with `?ts=YYYYMMDDTHHMMZ` so you can copy/paste a single link that opens with the same seed pre-filled.
- **Open button**: next to the share link, there is a one-click Open action (new tab) so you can sanity-check what someone else will see.

If you load the app with `?ts=...` and the TS is valid, it auto-initializes to that TS and updates the pick + artifact templates.

## Why this matters

The whole point of the six-hour loop is to be deterministic and low-friction. Deep links make it easier to:

- capture a seed in a note and return later,
- share a seed with someone else (or future-you) without retyping,
- keep the "same TS -> same pick" promise visible.

## Next step (idea)

Add an optional `?n=` and `?step=` (hours) query param so a shared link can also open with a prebuilt schedule preview (and maybe an auto-copied markdown block).
