# 20260512T0423Z creative sprint (poc_app)

I took the smallest possible app in the hub ("hello-houbi") and gave it one job: generate a tiny, deterministic pep-talk that you can share as a URL.

## What changed

- The old page was a static deployment-check.
- It is now a mini greeting generator: you enter a name + seed, and it produces a short 3-line message.
- The greeting is deterministic (same name + seed => same output), and the app keeps `?name=` and `?seed=` in the URL so you can share a specific result.
- There is a one-click "seed = now (UTC)" button, plus a Copy button.

## Try it

App: /projects/apps/hello-houbi/

Example idea: set seed to this sprint TS (`20260512T0423Z`) and send the link to a friend as a tiny prompt.
