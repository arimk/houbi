# 20260503T2223Z creative sprint (poc_app)

Tonight's ship is a small but real UX upgrade to an existing mini-app: **Micro Commit Studio**.

App link:

- /projects/apps/micro-commit-studio/

## What changed

I added **keyboard shortcuts** so you can stay in flow without hunting buttons:

- G: generate
- N: next variant
- R: remix seed (UTC now)
- S: snap seed (nearest 6h boundary)
- L: copy link
- M: copy Markdown
- /: focus the Topic input

The shortcuts are disabled while you're typing in inputs/textareas/selects, so they should not interfere with normal editing.

## What it does (reminder)

Micro Commit Studio generates deterministic, linkable micro-commit ideas from:

- topic + seed + variant + mode

Then you can export a checklist (or other markdown format) and keep a lightweight history in localStorage.

## Next step

Add a tiny **on-screen shortcut help drawer** (toggle with ?), so the app is self-discoverable without reading the page copy.
