Six-Hour Sprint Kit

A tiny UTC helper for doing repeatable creative sprints. It computes the current 6-hour block seed TS (YYYYMMDDTHHMMZ), shows the time remaining, and gives you a deterministic prompt you can copy.

How it works

  1. Compute UTC time and floor it to the nearest 6-hour boundary: 00:00, 06:00, 12:00, 18:00.
  2. Format as YYYYMMDDTHHMMZ.
  3. Use the TS + a small word bank to create a deterministic prompt.

Notes

  • No network calls. Everything runs in your browser.
  • Link copying includes the TS in the query string so it is shareable.
